# ghdl —— GitHub 代理下载小工具

粘贴一个 GitHub 链接，指定一个目录，它自己找能用的加速源把文件下下来，下完顺手校验。
本机网页版：Python 起一个只监听 127.0.0.1 的小服务，浏览器操作，不用装任何额外东西。

## 怎么用

**最简单：双击 `ghdl.exe`** → 浏览器自动打开 `http://127.0.0.1:8765/`。它不依赖 Python（Python 卸载了也能跑），
没有命令行窗口，要停止就在**页面右上角按「停止服务」**。

> **拿现成的**：去 [Releases](../../releases) 下载 `ghdl.exe`（单文件，不需要装 Python）。
> 它**没有代码签名**，Windows 首次运行会弹 SmartScreen「已保护你的电脑 / 未知发布者」——
> 点「更多信息 → 仍要运行」即可；Release 说明里附了 SHA256，不放心可以先比对再跑。
> **自己打一个**：双击 `打包.bat`，产物在 `dist\ghdl.exe`，会自动复制到本目录（需要
> `python -m pip install pyinstaller`）。源码全公开，比对哈希后自己打包是最稳的路。
> `ghdl.spec` 也不进仓库（那是 PyInstaller 每次重新生成的产物，且含生成机器的绝对路径）。
> 不想装任何 Python 包的话，`start.bat` 那条路功能完全一样，只是多一个命令行窗口。

也可以用 `start.bat`（会留一个黑色命令行窗口，关窗口就是停止；好处是改完 `server.py` 立刻生效，不用重新打包）。

> 两个共用同一个 `data/`，所以历史是同一份 —— 但**别同时开两个**：第二个会换端口（8766…），
> 你会看到两个页面各管一个服务，容易分不清。选一个用就行。

首次运行会在同目录自动生成 `data/`。不需要管理员权限，不写注册表。

界面固定**可爱**风格（奶油粉 + 白卡片 + 胶囊输入框），想换风格是改一行代码，见下面「风格与动效」。

### 重新打包

改了代码想用 exe 版本时，双击 `打包.bat`：它调 PyInstaller 重新生成 `dist\ghdl.exe` 并复制回本目录。
需要先装过 PyInstaller（`python -m pip install pyinstaller`，这台机器已装好）。
**只是改样式或改 `server.py` 的话不必打包** —— 用 `start.bat` 那份就是源码直跑，即时生效。

界面从上到下几块：

1. **下载** —— 贴链接、给目录、按「开始下载」
2. **任务** —— 进度条、实时速度、当前用的是哪个源、第几次尝试、过程日志
3. **校验本地文件** —— 不想重新下载，只想确认磁盘上这个文件完不完整
4. **代理源** —— 测速、启用/停用、加自己的源、调顺序
5. **历史** —— 下过什么、多大、走哪个源、SHA256、校验结论，点「打开」直接定位到文件

界面固定**可爱**风格（奶油粉+白卡片+胶囊输入框）。想换风格是改一行代码，不是点按钮 —— 见下面「风格与动效」。

### 校验本地文件怎么用

填文件路径（或按「选文件…」在文件夹里点到它），想比对作者公布的哈希就把原来的下载链接也填上（选填），
按「开始校验」。结果出现在上面的任务列表里，标着「本地校验」。几 GB 的文件要等几十秒，期间可以取消。
这条**不写进历史**（历史只记下过东西，免得混进没下的条目），也不改动文件本身。

### 每步该看到什么（判据）

| 动作 | 正常的样子 |
|---|---|
| 双击 `ghdl.exe` | 没有窗口出现（正常，它是后台服务），一两秒后浏览器自动打开页面；要停就按页面右上角「停止服务」 |
| 双击 `start.bat` | 命令行窗口出现 `ghdl 就绪 → http://127.0.0.1:8765/`，几秒后浏览器弹出页面 |
| 按「停止服务」 | 没任务时立刻变「已停止」并置灰，进程真的退出（可以打开任务管理器确认没有 python/ghdl 残留）；有任务在跑时它会先拦住，让你再按一次「强制停止」 |
| 打开页面 | 一打开页面顶部就是第一张卡「下载」（不是停在中间）；右上角绿色「服务在线 · 已运行 …」；整体奶油粉+白卡片；代理表已列出 gh-proxy.com / ghfast.top / ghproxy.net / 直连 四行 |
| 贴好链接按开始 | 任务卡立刻出现，徽标从「排队中」→「解析链接」→「选源」→「下载中」，进度条走动，速度有数字 |
| 下完 | 徽标变绿「完成」，下面一行校验结果：`SHA256 xxxx… · zip 全量 CRC 通过（N 个条目） · 签名有效（…）` |
| 某个源不行 | 日志里多一条「第 2 次尝试：<下一个源>」，不会从头重下（大文件会看到「从 X 处续传」） |
| 全部源都不行 | 徽标「失败」，日志逐条写明每次尝试的 http 码和 curl 退出码，历史里留一条带「失败」标记的记录 |
| 按「开始校验」 | 任务列表出现一张「本地校验」的卡，走「校验中 → 完成」，没有下载进度条（本来就不下载） |

### 支持贴哪些链接

全都直接原样粘贴，程序自己认：

```
https://github.com/作者/仓库/releases/download/v1.0/文件名.exe   release 里的某个文件
https://github.com/作者/仓库/raw/main/docs/a.md                  仓库里某个文件（blob 链接也认）
https://github.com/作者/仓库/archive/refs/heads/main.zip         整仓打包
https://github.com/作者/仓库                                      仓库首页 → 默认下整仓 zip；选「强制 git clone」就浅克隆
https://github.com/作者/仓库/releases                             发布页 → 按「列出该页文件」挑
https://gh-proxy.com/https://github.com/...                       已经套过代理的加速链接（会先剥掉）
```

## 常见报错对照

日志里出现的 `curl退出码` 是什么意思、该怎么办：

| 现象 | 含义 | 怎么办 |
|---|---|---|
| `http=404 curl退出码=22` | 链接指向的文件不存在（release 里没这个文件名，或分支名错了） | 回页面右键复制真正的下载链接 |
| `http=403` | 该源拒绝了这个请求（有的源屏蔽大文件或不认 raw 链接） | 换源重试即可，程序会自动换 |
| `curl退出码=35` | TLS 握手失败（校园网访问证书吊销列表常抽风，多为直连那条） | 不用管，它会自动换代理源 |
| `curl退出码=6` | 这个代理域名已经失效（DNS 都解析不了） | 到「代理源」里停用它，或去 [gh-proxy 项目](https://github.com/hunshcn/gh-proxy) 找个新站加进来 |
| `curl退出码=18` | 源下到一半断了 | 正常，会自动换源续传，看下一条 |
| 「连续 30 秒没动静，已经停掉它换下一个」 | 源连上了但不给数据 | 程序自己处理了，不用管 |
| 「最近 15 秒只有 xx/s」 | 源太慢（默认门槛 2 KB/s） | 阈值在 `data/config.json` 的 `speed_floor_bps` 可调 |
| 「这个源 它回了 416」 | 那个源不支持断点续传 | 程序会删掉半截、同一个源从头再来一次 |
| 历史里 `与官方校验值对不上！` | 文件内容跟作者公布的 SHA256 不一致 | **先别装**，换源重下；仍不一致就是链接被人换过了 |
| 页面右上角红色「连不上后台」 | 命令行窗口被关了 | 重新双击 `start.bat` |

## 风格与动效

界面固定用**可爱**风格：奶油粉背景、白卡片、胶囊输入框、大圆角、渐变页眉、悬停有粉色软阴影。
右上角不再放主题切换器。

想换成别的风格：改 [static/index.html](static/index.html) 顶部那行内联脚本里的一个词就行 ——

```js
document.documentElement.dataset.theme = 'cute';   // cute 可爱 / simple 简约 / dark 深色 / paper 护眼米色
```

四套的配色都在 `static/style.css` 开头各自的变量袋里，改颜色就改那一袋。
再加一套：复制一袋 `:root[data-theme="你的名字"]{...}`（36 个变量都得给齐，少一个自测报错），
主题专属的外观写在「主题专属的外观」那段，**不要写死颜色到共用区**（自测有断言盯着）。

动效：卡片依次淡入入场、新任务淡入、**下载中进度条有反光横扫**、拿不到总大小时进度条呼吸、
**完成时卡片晃一下（tada）、失败时左右摇头（headShake）**、提示条从顶上落下、release 文件列表逐行缩放进来。
Windows 设置里开了「显示中减少动画」的话，这些全部自动降级为瞬间到位。

入场动画刻意用**纯透明度**的 fadeIn，不用带向下位移的 fadeInUp：被 transform 移出去的内容会扩大页面
可滚动范围，`fill-mode` 又把它按在下方状态直到延迟结束，打开时看着就"不在顶上"。前端另外有一句
`window.scrollTo(0, 0)` 兜住浏览器恢复旧滚动位置的情况。

### 动效是哪来的

用的是 [animate.css v4.1.1](https://github.com/animate-css/animate.css) 的关键帧，但**不是引 CDN**——
本工具是给"GitHub 打不开的时候"用的，页面绝不能依赖外部资源，自测里有一条专门扫前端有没有外部
`src/href/@import`，出现就报错。做法是把用到的几个动画原样摘进本地 `static/animate.css`（5.5 KB，
原文件 95 KB），文件头写明出处，许可证全文随附在 `static/ANIMATE-LICENSE.txt`。

注意 animate.css v4 **不是 MIT**，是 **Hippocratic License 2.1**（版权 Daniel Eden），所以出处和许可证文本
都保留了。想再加动画：先在 `static/animate.css` 里从官方源码补一段对应 keyframes，再在 `style.css` 用。

## 数据放哪

全在 `data/` 里，纯文本，想改直接改（改完刷新页面即可，不用重启）：

- `proxies.json` —— 代理源列表（`prefix` 就是拼在完整地址前面的那段）
- `config.json` —— 默认目录、常用目录、端口、判卡死的阈值、是否校验
- `history.json` —— 最近 300 条下载记录
- `server.log` —— 运行日志，出问题先看它

想彻底删掉这个工具：把 `githubDownload` 整个文件夹删了就走，不留任何东西。

## 自测

改了代码之后双击 `自测.bat`（或本机命令行 `py -3 selftest.py`）。它会用临时目录和备用端口起一个独立实例，
不碰你真正的配置和历史，跑 90 多项检查（含真下载、断线换源、假源识别、前端资源与主题一致性），
最后打印「全部通过」。目录里有 `ghdl.exe` 时，它还会**把 exe 也起一遍**：验它能起来、页面在包里、
能真下完文件、`data/` 落在 exe 旁边、以及页面那个停止按钮真的能把进程关掉。
想看它每一步的下载日志，加个环境变量：`set VERBOSE=1` 再跑。

**校园网抽风时它会老实说**：自测开头要先取一个参考文件（依次试 gh-proxy.com → ghfast.top →
ghproxy.net → 直连，每个重试两轮），全都取不到就只报前面离线检查的结论，然后写明
"联网部分测了也不可信，本轮跳过"，退出码 3，**不会把网络问题报成代码的错**。

## 已知边界（不做，说明白）

- 只加速**下载**。GitHub 网页本身打不开不是它的事（那要 dev-sidecar / FastGithub 那种改 hosts 的方案）。
- 不做多源分块并发下载。单源已经能跑到 30~45 MB/s，够快。
- 服务只监听 127.0.0.1，没有登录鉴权 —— 别把它改绑到 0.0.0.0 暴露到校园网。
- 半截文件（`.part`）只在**同一个任务换源时**续传。取消或失败后重新点下载会另起文件名（`(2)`），不从半截接。
- 文件总大小拿不到时（少数源不分块返回），进度条用呼吸态表示"不知道还剩多少"，只显示已下字节数。
- 取 release 文件列表要问 `api.github.com`，这个域名在这台机器上时好时坏；不通时就回落到"你自己右键复制直链"。
- 校验能证明"文件完整、签名有效、和作者公布的哈希一致"，不能证明"这个作者可信"。

## 想自己搭一个不会失效的源

现成站子活不过几个月。想要长期稳定的，用自己的 Cloudflare Workers 部署 [hunshcn/gh-proxy](https://github.com/hunshcn/gh-proxy)：
把 `worker.js` 内容贴进 Workers 新建项目、部署、拿到 `https://xxx.workers.dev/`，
回到本工具「代理源」里添加它，测一下速度，就能一直用自己的那条路。免费额度对个人下载完全够。
